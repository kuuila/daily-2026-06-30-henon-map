# Henon Map — Butterfly Attractor

> 一只蝴蝶扇动翅膀，另一只蝴蝶的轨迹永远偏离

## 蝴蝶效应原理

Hénon 映射是 1963 年 Hénon 从 Poincaré 截面研究中发现的二维混沌系统：

```
x_{n+1} = 1 - a·x_n² + y_n
y_{n+1} = b·x_n
```

当参数 **a=1.4, b=0.3** 时，系统进入混沌状态，Lyapunov 指数 λ ≈ 0.42 > 0。

**蝴蝶效应的核心**：初始值 x₀ 改变 0.001，经过约 20 次迭代后两条轨迹完全分叉。这比 Logistic 映射更快、更剧烈——二维相空间允许轨道在平面上编织出著名的**蝴蝶形吸引子**，分形维数 ≈ 1.26。

每一次迭代都是一次"扇动翅膀"，吸引子的精细结构是无限递归的蝴蝶阵列。

## 代码核心

- **Logistic Map** 只有一维，Hénon Map 引入了二维相空间，轨道可以在平面上打结
- 使用 **ncurses** 实时绘制，headless 模式用 `--save output.ppm` 导出 PPM 图像
- 两条轨迹初始差仅 0.001，肉眼可见轨迹在几次迭代后完全分离

## 编译

```bash
g++ -O2 -std=c++17 main.cpp -lncurses -o henon
```

## 运行

```bash
./henon              # 交互式 ncurses 可视化
./henon --save out.ppm  # 导出 PPM 图像（无终端依赖）
```

## 交互

- `q` — 退出
- `r` — 重置轨迹
- `+/-` 或 `↑↓` — 调整延迟（速度）

## 分形自相似性

放大 Hénon 吸引子的任何区域，你会发现它包含与整体相似的结构——在大海中有湖泊，在湖泊中有岛屿，在岛屿中有池塘，无限嵌套。这正是分形的核心特征：自相似性 + 非整数维数。
